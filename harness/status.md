- 고유 투명 WebP 이미지 50개와 표본별 이름·설명·분류·등급·재질·참고 링크를 연결했다. 기본 제공 image_gen으로 49개 신규 생성, 11번 기존 이미지 원본 재사용. 생성 원본은 보존했다.
- 도감은 3열 50칸. 미발견 `???`, 발견하면 이미지·이름·희귀도·중복 횟수 공개. 범주/희귀도/발견 필터와 상세 관찰을 제공한다. 홈에서도 다양한 표본 예시를 보여준다.
- 시작 시 등급 60/28/10/2%를 추첨하고 등급 내부 균등 선정한다. 24/15/8/3종으로 정규화했다. 27번 로즈쿼츠 조정과 C 카테고리 12종 정정은 D007에 기록하고 원본은 보존했다.
- 종별 최초/마지막 발견일·중복 횟수와 고유 수집률을 기록한다. 저장 version 1 암모나이트 기록을 version 2의 11번으로 이전한다.
- 지역 손상·균열·4층 제거·파편·먼지·망치/브러시를 유지한다. 90%부터 브러시 필수, 계속 망치로 100%면 파손 실패다. 실패로 기존 기록은 잃지 않는다. 재질별 색/합성 타격음과 등급별 공개 연출을 구분한다.
- 완료 화면은 표본 크기를 조절해 도감 보기 버튼이 하단 메뉴에 가리지 않도록 수정했다.

## 기반 세팅

공식 create-ait-app의 React/TypeScript/Vite, SDK 3.8.1을 사용한다. ait 0.2.6·Playwright·Figma·fossil-experience 세팅을 유지한다. 기존 짐싸줘와 소스/앱 ID/광고 ID/빌드를 분리했다. Figma 설치/활성화 확인 기록은 있으나 이 세션의 Figma API 도구·계정/파일 접근은 미검증이며 이번 구현은 로컬 앱에서 진행했다.

## 남은 범위

- 소리는 직접 합성한 임시 효과음이다. 실제 녹음 ASMR/사람의 청취 검증은 없다. 이미지도 인증된 출토 사진이 아닌 생성형 시각 재구성이며 과학적 검수가 남았다.
- iOS/Android 토스 WebView·SDK 저장·장시간 성능/메모리·실제 콘솔 appName/분류·광고·제출/심사는 미검증이다.
- 진행 중 발굴은 탭 이동 시 유지되지만 새로고침/앱 종료 후 초기화된다. 발견 기록과 설정은 브라우저 저장소에 유지한다.
- 콘솔 최종 앱 식별자와 광고 설정은 미정이다. 현금성 보상은 없다.
