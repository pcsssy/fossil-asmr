# 제품 기준

앱 이름: 화석발굴. 영문 가칭: Fossil ASMR. 타깃은 Apps in Toss 모바일 WebView.

핵심 경험은 **두드린 자리에 균열과 깊이가 남고, 파편·먼지·소리가 즉시 반응하며, 암석 속 표본이 점진적으로 드러나는 과정**이다. 화면 수보다 이 경험이 우선이다.

## 범위와 단계

1. 암모나이트 1종: 실제 질감, 지역 손상, 층 제거, 타격음, 완전 노출, 재시작.
2. 브러시, 사운드 레이어, 파편 물리, 대표 6종의 재질 차이, 성능 조절.
3. 50종의 데이터·에셋·등급 확률·중복 기록·도감.
4. 홈·발굴·공개·도감·상세·설정, 영속 저장.
5. 광고·SDK·아이콘·AIT 빌드·실기기·심사 준비.

대표 6종: 티라노사우루스 두개골 / 암모나이트 / 다이아몬드 원석 / 자수정 / 조개 화석 / 삼엽충.

## 유지할 제품 규칙

- 한 회차의 결과는 시작 시 선정하고 완료 전 숨긴다. 광고 시청으로 결과를 조작하지 않는다.
- 전체 목표 확률은 노멀 60%, 레어 28%, 스페셜 10%, 전설 2%. 등급 안에서는 균등 선택한다.
- 중복 발굴을 허용하며 횟수·최초 발견일을 저장한다. 정의 데이터와 사용자 기록을 분리한다.
- 임시 에셋과 미구현 콘텐츠를 완성품으로 표시하지 않는다.
- 광고는 발굴 입력 영역에서 분리하고 발굴 중 전면 광고를 띄우지 않는다.
- 초기 MVP에는 실제 포인트·현금성 보상을 넣지 않는다.

## 확인이 필요한 사항

- 원본 목록 23/16/8/3종은 D007에 따라 27번 로즈쿼츠를 노멀로 조정해 24/15/8/3종으로 정규화했다. 원본은 보존한다.
- C 보석·광물 제목의 11종은 실제 목록대로 12종으로 정규화했다. 전체 50종 ID는 유지한다.
- 수집·확률형 발굴의 실제 기능에 따른 게임/비게임 분류는 최신 심사 기준으로 확인한다.
- 실제 appName, 광고 그룹 ID, 필요시 저장 API는 콘솔 및 공식 SDK 확인 전 미정이다.
