# 50종 전체 콘텐츠 검증 — 2026-10-24

사용자 요청: 암모나이트 이외의 나머지 표본을 실제 발굴 콘텐츠로 구현한다. 이전 1종 프로토타입/49개 준비 카드 상태를 대체했다. 기존 짐싸줘 앱은 수정하지 않았다.

## 구현

- 고유 표본 50종: 공룡 10, 암모나이트 8, 광물 12, 조개 8, 식물 7, 삼엽충 5. 각각 독립된 이미지·설명·분류·등급·재질·참고 링크를 갖는다.
- 49개 신규 이미지는 기본 제공 image_gen으로 개별 생성했다. 기존 11번 이미지 원본은 재사용했다. 원본은 Codex generated_images에 보존하고 배포용 768px 투명 WebP 50개를 `app/public/assets/specimens/`에 저장했다. 전체 프롬프트·원본 경로·변환 메타데이터: [specimen-generation.json](specimen-generation.json).
- 50개 비트맵 SHA-256이 모두 다르다. 총 9,327,518 bytes, 최소 153,932 / 최대 209,966 bytes. 해상도·알파·빈 이미지·출처 검사를 통과했다. 인증된 과학 표본 사진이 아닌 시각적 재구성이다. 에셋 등록 총 53개는 임시 상태를 유지한다.
- 등급 수 24/15/8/3, 등급 확률 60/28/10/2%. 등급 내부 균등 선택. D007에 따라 27번 로즈쿼츠를 노멀로 정규화하고 원본 프롬프트는 보존했다. 설정에 개별 확률과 중복 가능성을 표시한다.
- 종별 최초/마지막 발견일·중복 횟수, 총 발굴 횟수, 고유 수집률을 저장한다. version 1 암모나이트 기록을 version 2의 11번으로 이전한다. 파손은 해당 회차만 실패하고 기존 기록은 유지한다.
- 90%부터 브러시 필수, 망치 100%는 파손이라는 사용자 규칙을 유지한다. 재질별 암석 색·합성 타격음과 희귀도별 공개 빛/합성음을 구분한다. 홈에 다양한 표본 예시를 추가했다.
