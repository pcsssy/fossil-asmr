## 변경한 동작

- 3열 카드 도감 50칸, 6개 범주 필터, 발견한 표본만 필터. 미발견은 `???`, 현재 미구현 49칸은 `준비 중`. 실제 획득한 암모나이트만 11번 카드에 이미지/이름/발견 완료를 표시하고 상세 모달에서 최초 발견일·누적 횟수를 확인한다.
- 기존 저장 데이터 키/스키마를 유지해 예전 암모나이트 획득 기록이 그대로 카드에 표시된다.
- 지점별 실질 노출 90%에서 브러시 필수 단계로 전환한다. 별도 먼지 필드를 지역적으로 지워 90% 이상 청소하면 성공한다. 한 지점만 반복해서 문질러서는 전체 마무리가 되지 않는다.
- 이 단계에서 망치를 계속 쓰면 한 번당 2.5%p씩 위험 진행률이 증가하고 100%에서 파손 실패한다. 90%에서 바로 계속 두드리면 추가 4회가 한도다. 브러시를 일부 쓴 후에는 현재 진행률을 기준으로 더 빨리 파손될 수 있다.
- 실패 시 현재 암석/표본을 9개 질감 조각으로 나눠 이동·회전·낙하시키고 파편·먼지·낮은 합성 파손음을 재생한다. 모션 감소 상태는 정적인 분리 표현을 사용한다. 성공용 공개음은 실패에서 재생하지 않는다.
- 실패 회차는 도감에 등록하지 않는다. 이전 획득 기록은 보존한다. 성공/파손 후 추가 입력은 상태를 바꾸지 않는다.
