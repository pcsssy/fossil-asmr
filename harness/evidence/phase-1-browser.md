# Phase 1 브라우저 검증 — 2026-10-24

## 구현 범위

대표 암모나이트 1종. 홈·발굴·공개·1종 도감·확대·설정. Canvas 2D의 100×100 지역 손상 필드와 4개 암석층, 분기 균열, 중력 파편, 먼지, 망치/브러시, 공개 줌, 입력 기반 임시 합성 사운드를 구현했다. 도감 발견 횟수·최초 발견일과 설정을 브라우저 저장소에 저장한다. 앱 내 탭 이동은 진행 중 손상을 보존하지만 새로고침 시 진행 중 발굴은 초기화된다.

## 통과한 검사

- 순수 로직 5개: 지역 손상과 원거리 불변, 한 지점 연타로 전체 완료 불가, 분산 타격 완료·완료 후 불변, 회차별 중복 기록 방지, 저장 손상/버전/용량 오류.
- `scripts/browser-audit.js`의 브라우저 검사 20개: 모바일 4개 폭의 가로 넘침, 설정 유지, 실제 픽셀의 지역 변화·원거리 불변, 오디오 활성화·신호, 탭 이동 시 손상 보존, mute, 브러시, 재시작, 완료·도감 저장, 확대, 새로고침, 회전, 저장 실패·재시도, 런타임 오류 부재.
- `scripts/browser-edge-audit.js`의 추가 검사 12개: 320×720/360×740/390×844/430×932에서 도구가 하단 메뉴에 가리지 않음, 60회 연타의 지역성·파편 상한·정리, 키보드, pointercancel 오류 부재, 이미지 로딩 실패·재시도, 낮은 품질의 해상도 제한.
- 분산 타격 패턴: 30회에 노출 기준 도달. 탭 횟수 카운터가 아닌 표본 영역의 실질 노출률 90%에서 마지막 가장자리 정리 연출을 시작한다.
- 브라우저 오디오: 사용자 입력 후 AudioContext=running, 최종 실행 analyser RMS peak 약 0.0450 (35% 볼륨; 변주에 따라 수치가 다름). 실제 음성 신호가 출력 경로에 도달함을 검사한 것으로, 청취 품질 보증은 아니다.
- 실제 렌더의 텍스트/배경 대비를 검사하고 보조 문구·도감 라벨을 어둡게 수정했다. 최종 홈·발굴·발견 후 도감에서 검사 대상 텍스트의 4.5:1(큰 텍스트 3:1) 미달 항목은 0개였다. 이는 화면낭독기나 모든 상태를 포함하는 접근성 인증이 아니다.

## 제한적인 데스크톱 측정

Windows HeadlessChrome 155, DPR 1, 고품질, 390×844, 60회 연타와 잔여 애니메이션 약 107프레임의 rAF 간격: 중앙값 16.7ms, p95 20.4ms, 최대 33.2ms. 입자 수 최대 240개로 제한되며 종료 후 0으로 정리됐다. 조용해지면 캔버스 자체 rAF 루프가 중단됨을 확인했다.

측정에는 자동화·스크린샷 오버헤드가 있고 표본 수가 작다. 모바일 WebView 60FPS 달성이나 장시간 메모리 안정성을 의미하지 않는다. 모바일 메모리는 아직 측정하지 않았다.
