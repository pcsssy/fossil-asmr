# 아트 디렉션 — 빛이 드는 발굴 연구실

오래된 표본과 현대적인 박물관의 여백을 결합한다. 따뜻한 종이색 배경 위에 실제 질감의 암석을 크게 놓고, 작은 라벨과 차분한 타이포그래피가 표본을 설명한다. 발굴의 주인공은 암석과 발견물이다.

`design-tokens.css`가 코드로 옮길 토큰 초안이다. 이 값들은 TDS 인증을 뜻하지 않는다. 일반 텍스트 대비 4.5:1, 큰 텍스트 및 필수 UI 대비 3:1을 실제 조합으로 검사한다. 희귀도는 색과 한글 라벨을 함께 사용한다.

폰트: 우선 시스템 한글 산세리프. 제목 28–32px/1.3, 섹션 20px/1.4, 본문 16px/1.55, 메타 12–13px/1.45. 작은 수치와 영문 표본 번호는 보조로만 쓴다. 공개 폰트 추가 시 라이선스와 오프라인 동작을 기록한다.

간격은 4·8·12·16·24·32px. 화면 좌우 20–24px. 주요 버튼 높이 56px, 터치 영역 최소 48px. 패널 반경 20px, 알약은 필터에만 사용한다. 짙은 그림자·모든 영역의 카드화·과도한 반투명 효과를 피한다.

## 화면 구성

| 화면 | 시선 순서와 행동 |
| --- | --- |
| 홈 | 앱 이름/설정 → “돌 속에 무엇이 숨어 있을까요?” → 중앙 암석 조형 → “발굴 시작하기” → 실제 발견 기록 → 홈/발굴/도감 |
| 발굴 | 뒤로/사운드 → 최소한의 안내 → 화면 중심을 넓게 쓰는 암석 → 진행 힌트 → 하단 망치/브러시. 손가락 아래에 중요 정보를 놓지 않는다 |
| 공개 | 마지막 암석 탈락 → 표본 클로즈업 → 이름·등급·신규 여부 → 도감 보기/다음 발굴 |
| 도감 | 수집률 → 카테고리/등급/발견 필터 → 3열 수집 카드판 50칸. 번호·`???`·미발견 상태, 발견한 표본은 고유 이미지·이름·등급·중복 횟수. 카드를 눌러 상세 관찰 |
| 상세 | 확대 가능한 표본 → 이름/분류/시대 → 짧은 관찰 정보 → 발견 기록·이미지 출처 |
| 설정 | 사운드/볼륨/진동/품질/모션 감소/흔들림/확률/앱 정보 |

빈 도감, 저장 실패, 음원 로딩 실패, 오프라인, 발굴 중 이탈 복귀도 설계한다. 없는 기록에 가짜 발견 수치를 넣지 않는다.

2026-10-24 변경: 90%부터 브러시 전환 배너를 표시한다. 망치 선택은 유지해 사용자가 직접 바꾸되 위험 문구와 브러시 강조로 안내한다. 파손 시 조각 분리/낙하 후 명확한 실패 문구와 재도전 버튼을 보여준다. 이미 수집한 표본은 실패로 잃지 않는다.

## 재질과 조명

- 좌상단 부드러운 단일 주광, 우하단 접촉 그림자. 암석의 표면/절단면/내부층은 거칠기와 명도 차이로 구분한다.
- 암모나이트는 불규칙한 외곽, 나선 봉합선, 석회암 매트릭스가 보인다. 단순 나선 아이콘으로 대체하지 않는다.
- 자수정은 결정면·투과감·군집 그림자, 다이아몬드 원석은 자연 결정형과 제한된 하이라이트를 쓴다. 모든 광물을 같은 반짝임으로 처리하지 않는다.
- 표본은 같은 카메라 각도·광원·중심 배치·여백을 유지하고 실루엣은 명확히 구별한다.
- 생성 이미지에는 글자·UI·워터마크·공중에 뜬 파편을 넣지 않는다. 암석층, 표본, 그림자, 파편은 조합 가능한 에셋으로 분리한다.

## 모션 초안

입력과 같은 프레임에 균열·파편을 발생시키고 타격 애니메이션은 80–140ms, 먼지는 250–500ms, 파편은 300–700ms, 최종 공개는 600–900ms 범위에서 튜닝한다. 이는 목표값이며 측정값이 아니다.

카메라 흔들림은 국소적이고 짧게, 모션 감소 시 흔들림·줌을 끈다. 모션 감소에서도 실제 손상과 진행 정보는 유지한다. 빠른 섬광은 사용하지 않는다.

## 시각 검토 절차

320/360/390/430px 폭과 가로 회전에서 실제 렌더를 확인한다. 홈/초기/중간/완료/도감 빈 상태/설정의 스크린샷을 남긴다. 안전 영역·텍스트 줄바꿈·손가락 가림·파괴 깊이·표본 실루엣을 검토하고 수정한다. 이미지 한 장의 시안과 실행 화면을 구분해서 보고한다.
