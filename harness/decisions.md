# 결정 기록

## D001 — 기존 앱과 분리 (2026-10-24)

현재 루트가 짐싸줘 앱이므로 화석발굴 준비 파일을 `fossil-asmr/`에 둔다. 후속 런타임은 `app/`에 생성한다. 사용자가 별도 작업 폴더를 지정하면 구조를 옮길 수 있다.

## D002 — 체험 품질 먼저 (2026-10-24)

첫 표본은 암모나이트. 1종의 재질·지역 파괴·오디오를 확인한 뒤 대표 6종으로 확장한다. 50종 데이터 완성만으로 제품 완성 판정하지 않는다.

## D003 — 원본 카탈로그 불일치 보존 (2026-10-24)

목표는 24/15/8/3종인데 원본 목록은 23/16/8/3종이다. 현재 재분류하지 않는다. 후속 콘텐츠 작업에서 레어 1종을 노멀로 조정하는 안을 결정하고 이유·변경 항목을 기록한 뒤 엄격 검증을 통과시킨다. 등급 확률 60/28/10/2는 별도 유지한다.

추가 발견: C 제목은 11종이지만 실제 19–30번은 12종이다. 현재 목록 자체는 총 50종이며 제목에 쓰인 카테고리 수의 합은 49종이다. 후속 정정은 원본 파일을 고치지 않고 정규화 카탈로그와 결정 기록에 반영한다.

## D004 — Phase 1 렌더링과 사운드 (2026-10-24)

Canvas 2D를 선택했다. 100×100 지역 높이 필드와 4개 텍스처/마스크로 손상을 유지하며 React는 메뉴·진행 라벨을 담당한다. 각 타격은 위치 기반이고 완료는 중심 표본의 90% 실질 노출 기준이다. 분산 패턴 30회에 완료되어 초기 목표 범위에 들어왔다. 고품질 입자는 240개, 낮은 품질은 100개로 제한한다. 데스크톱 측정 결과만 있으며 모바일 WebGL 전환 필요성은 실기기 측정 후 판단한다.

라이선스를 확인한 녹음 샘플을 아직 확보하지 않았으므로 직접 합성한 Web Audio 효과음을 임시 사용한다. 사용자에게 개발 버전/합성음/생성 이미지임을 설정에 표시한다. 프로토타입 저장은 브라우저 localStorage이며 SDK 저장 어댑터 검증은 후속 작업이다.

## D005 — 모바일 발굴 도구 노출 (2026-10-24)

390px 전체 폭의 정사각형 캔버스는 작은 기기에서 도구를 하단 메뉴 뒤로 밀었다. 화면 높이에 따라 200–390px로 캔버스를 조절하고 입력 좌표는 동일한 600×600 논리 공간으로 변환한다. 320×720부터 430×932까지 도구/하단 메뉴 비겹침을 검증했다.

## D006 — 카드 도감과 브러시 필수 마무리 (2026-10-24, 사용자 요청)

단일 표본 상세 화면 중심이던 도감을 번호가 있는 3열 카드판 50칸으로 변경했다. 미발견은 `???`와 실루엣/미지의 표시로, 미구현 49종은 `준비 중`으로 명시한다. 50종을 모두 발굴할 수 있다는 뜻이 아니다. 기존 발견 기록은 11번 암모나이트 카드로 표시하며 삭제/초기화하지 않는다. 범주 필터와 발견한 표본만 필터를 제공한다. 출시 전 확률 카탈로그의 등급 불일치는 여전히 미해결이다.

기존의 망치만으로 완료 가능한 규칙은 사용자 요청으로 폐기했다. 지역 노출 90%에서 브러시 필수 단계로 전환한다. 마지막 먼지를 골고루 정리하면 성공, 망치를 계속 사용해 100%가 되면 파손 실패다. 90%에서 시작하면 추가 망치 4회가 위험 한도이며, 브러시를 일부 쓴 뒤에는 현재 표시 진행률을 기준으로 파손 한도가 짧아질 수 있다. 파손 회차는 등록하지 않고 기존 도감은 보존한다. 원본 프롬프트는 당시 요구의 기록으로 보존한다.

## D007 — 50종 전체 콘텐츠와 확률 정규화 (2026-10-24, 사용자 요청)

사용자가 암모나이트 이외의 전체 표본 구현을 요청했다. D002의 단계적 확장 계획을 넘어 원본 50종 전체에 고유 이미지·설명·재질·발굴 결과·종별 발견 기록을 연결한다. 카드의 `준비 중`은 제거하되 미발견 이름은 `???`로 유지한다. 완료 판정은 데이터 50행만으로 하지 않고 이미지 50개와 발굴 가능성까지 검사한다.

원본은 보존하고 정규화 데이터에서 27번 로즈쿼츠를 레어에서 노멀로 변경했다. 흔한 석영 계열을 노멀에 배치해 목표 24/15/8/3종을 맞춘다. C 카테고리는 실제 목록대로 12종이다. 등급 확률은 기존 60/28/10/2%를 유지하며 등급 내부는 균등 추첨한다. 설정에 등급별·개별 확률과 중복 가능성을 명시한다. 당첨 보정이나 확정 지급은 없다.

저장은 version 2로 확장하고 기존 version 1 암모나이트 발견 횟수·날짜를 11번에 이전한다. 다른 종 발견과 파손이 기존 기록을 지우지 않는다. 표본별 이미지 원본·전체 프롬프트·최적화 이력은 `evidence/specimen-generation.json`에 기록한다. 생성 이미지는 시각적 재구성이며 인증된 과학 표본 사진이 아니다.
